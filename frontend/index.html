Under the hood

How It Works

Every answer is grounded in the character's Arabic Wikipedia article, then spoken by the avatar.

  1. You ask

    Type a question, or speak it. Speech is recognised in Arabic directly in the browser.

  2. The facts are found

    The most relevant passages are retrieved from the character's Arabic Wikipedia article (RAG with FAISS).

  3. The character answers

    An AI model answers in the first person, in short Arabic, using those passages and your conversation so far.

  4. The avatar speaks

    A neural Arabic voice reads the answer while the 3D avatar's lips follow each word.

Features

Experience History Like Never Before

Voice conversations

Talk hands-free in an interactive session, or type if you prefer. The chat keeps the full history.

3D avatars with Arabic lip sync

Each Arabic word is turned into mouth shapes at the exact moment it is spoken.

Answers with sources

Every answer links to the exact Wikipedia sections it was based on, so you can read further.

Stays in character

Characters speak in the first person and know when an event happened after their time.

Remembers the conversation

Follow-up questions like “and what happened next?” work, and each visitor has a separate conversation.

Private and resilient

API keys stay on the server. Without an AI key, answers are quoted from Wikipedia, so the app still works.
